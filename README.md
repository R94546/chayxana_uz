# Choyxona.uz

Mobil ilova — O'zbekistondagi an'anaviy choyxona-restoranlarni avtomatlashtirish va bron qilish tizimi. Flutter va Firebase asosida ishlab chiqilgan.

## Asosiy imkoniyatlar

- Stol bron qilish va boshqarish
- Menyu va buyurtmalarni boshqarish
- Ko'p rolli kirish (client / choyxona_admin / choyxona_owner / superadmin)
- CRM tizimi
- Real vaqtdagi analitika

## Texnologiyalar

- **Frontend:** Flutter (Dart), Provider state management
- **Backend:** Firebase (Authentication, Cloud Firestore, Cloud Functions)
- **Lokalizatsiya:** Rus / O'zbek / Ingliz tillari

## Ishga tushirish

```bash
flutter pub get
flutter run
```

> Eslatma: ilovani ishga tushirish uchun Firebase konfiguratsiya fayllari (`google-services.json` va boshqalar) kerak. Ular xavfsizlik sababli repozitoriyga kiritilmagan.
